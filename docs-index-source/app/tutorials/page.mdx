# Learn how to use Grepr

These tutorials provide hands-on guidance for building and configuring Grepr data pipelines. Each tutorial walks through specific tasks with practical examples, from basic pipeline creation to advanced data processing scenarios.

## Build your first pipeline

This tutorial covers the fundamentals of creating a Grepr pipeline. You'll learn how to configure a source, add transforms to process data, and set up a sink to output results. By the end, you'll understand the basic pipeline structure and workflow.

See [Building your first pipeline](/tutorials/first-pipeline).

## Troubleshoot incidents with Grepr-processed data

Learn how to use Grepr to enhance your incident response workflows. This tutorial demonstrates how to use Grepr-processed data in an observability platform to quickly identify and troubleshoot issues.

See [Troubleshoot incidents with Grepr-processed data and your observability tool](/tutorials/troubleshooting-example).

## See how data flows through your pipelines and test changes

Learn how to use the live edit feature in the Grepr pipelines UI to see in real-time how data flows through your pipelines. This tutorial also shows you how to use live edit to safely test changes to your pipeline processing.

See [View pipeline data flows and test changes with live edit](/tutorials/live-edit).
