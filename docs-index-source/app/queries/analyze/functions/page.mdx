# Analyze function reference

These are the functions an [Analyze](/queries/analyze) expression can call. Log Explorer suggests the
same set from the expression box as you type.

An argument's type says what you may pass, not what the engine derives. `NUMBER` covers every numeric
type, because an attribute read with `@` has no declared type and is read as a number on demand — see
[attribute values](/queries/analyze#attribute-values). An argument in square brackets may be omitted,
and a trailing `…` means the argument may be repeated.

<Callout type="warning">
Analyze is not the SQL transform. A [SQL transform](/transforms/sql-transform) runs inside a pipeline
on Flink SQL and supports a different function library, listed in
[its own reference](/transforms/sql-transform/sql-functions). A function on that page may not exist
here, and the functions below are not all available there.
</Callout>
