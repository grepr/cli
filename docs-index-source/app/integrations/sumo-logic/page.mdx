# Configure Sumo Logic connections with a Grepr integration

The Grepr platform includes two integrations for connecting to Sumo Logic. This page documents the Sumo Logic integration, but the integration to use depends on the source type that you are sending logs to:

- If you use the OTLP/HTTP source in Sumo Logic, you must use the [Grepr OpenTelemetry integration](/integrations/open-telemetry) to connect Grepr and Sumo Logic.
- If you use the HTTP source, you must use the Sumo Logic integration.

To send logs to a Grepr pipeline before forwarding them to Sumo Logic, update your collector configuration to send the logs to a Grepr endpoint URL instead of the endpoint for a Sumo Logic source. To learn how to create a Sumo Logic integration in the Grepr UI and configure collectors to send logs to Grepr, see [Use a Sumo Logic integration in a Grepr pipeline](#use-sumo-logic-integration).

You can also use the Grepr REST API to create and use a Sumo Logic integration. See the [Sumo Logic Integration specification](/apis/api-spec#tag/Sumo-Logic-Integration).

## Requirements

- To create a Sumo Logic integration, you must have the endpoint URL from a configured `HTTP Logs and Metrics Source`. See [Configure an HTTP Logs and Metrics Source](https://www.sumologic.com/help/docs/send-data/hosted-collectors/http-source/logs-metrics/#configure-an-httplogs-and-metrics-source).
- The only log format supported by the Sumo Logic integration is JSON. To send logs to a Grepr source, you must set `log_format:json` in your collector configuration.

## Use a Sumo Logic integration in a Grepr pipeline [#use-sumo-logic-integration]

Use the following steps to create a Sumo Logic integration in the Grepr UI and use it in a pipeline to source and sink logs.

### Step 1: Create a Sumo Logic integration

To create a Sumo Logic integration in the Grepr UI:

1. Go to the **Integrations** page in the Grepr UI and click **Add new** next to **Observability Vendors**.
1. In the **Add Observability Vendor** dialog:
   - In the **Type** menu, select **Sumo Logic**.
   - In the **Name** field, enter a name for the integration. To facilitate working with logs in Sumo Logic, Grepr recommends naming the integration based on the collector that will send logs to Grepr.
   - In the **HTTP collector URL** field, enter the endpoint URL from your Sumo Logic `HTTP Logs and Metrics Source`.
1. Click **Create**.

   #### Optional: Grant team access to the integration

   <AddTeamAccess />

### Step 2: Add a source to your pipeline

To add a source to your pipeline that uses the Sumo Logic integration:

1. In the Grepr UI, go to the details page for an existing pipeline or create a new pipeline from the homepage.
1. In the left-hand navigation menu on the pipeline details page, click **Sources**.
1. In the **Add source** dialog, select the Sumo Logic integration in the **Source** menu.
1. Optional: In the **Name** field, to override the Grepr-generated name, enter a new name for the source.
1. Click **Submit**.

### Step 3: Configure log forwarding to Grepr

<IngestUrlConfig image_url='/images/integrations/ingestion-url-sumo.png' url='https://<integration-id>-<org-id>.ingest.grepr.ai/receiver/v1/http/<unique-http-collector>' />

Also replace `{$UNIQUE_HTTP_COLLECTOR}` with the unique identifier for your Sumo Logic `HTTP Logs and Metrics Source`.

The `Sumo Logic Distribution for OpenTelemetry Collector` is supported for sending logs to Grepr. To configure the OpenTelemetry collector to send logs to Grepr, set the `endpoint` value in the `exporters.sumologic` section to the ingestion URL from your Grepr source:

```yaml copy filename="config.yaml"
exporters:
  sumologic/grepr:
    endpoint: <ingestion-url>
    log_format: json

service:
  pipelines:
    logs:
      exporters: [sumologic/grepr]
```

Replace:
- `<ingestion-url>` with the ingestion URL from your Grepr Sumo Logic source.

Your workflow might require sending unprocessed logs directly to Sumo Logic in addition to sending the logs to Grepr. To configure dual-shipping of logs, include an exporter configuration for both Grepr and Sumo Logic in your OpenTelemetry collector configuration:

```yaml copy filename="config.yaml"
exporters:
  sumologic/grepr:
    endpoint: <ingestion-url>
    log_format: json

  # Your existing Sumo Logic exporter
  sumologic:
    endpoint: <sumo-http-source-url>
    log_format: json

service:
  pipelines:
    logs:
      exporters: [sumologic/grepr, sumologic]
```

Replace:
- `<ingestion-url>` with the ingestion URL from your Grepr Sumo Logic source.
- `<sumo-http-source-url>` with the endpoint URL from your Sumo Logic HTTP source.

To learn more about configuration settings for the Sumo Logic OpenTelemetry Collector, see the [Sumo Logic Distribution for OpenTelemetry Collector documentation](https://github.com/SumoLogic/sumologic-otel-collector#readme).

## Limitations

The integration doesn't support Sumo Logic [Extended HTTP Metadata Collection](https://www.sumologic.com/help/docs/manage/fields/#extended-http-metadata-collection). Grepr drops any custom headers forwarded by collectors before processing the messages included in the payload.
