# Release notes for September 2025

These features, improvements, and bug fixes for the Grepr Intelligent Observability Data Engine were released in September 2025.

## Configure multiple JSON parsers in the Grepr UI

**September 17, 2025**

To enable transformations of JSON messages that require more than a single step, you can now add multiple JSON parsers and attribute remappers when you configure your pipelines in the Grepr UI. To learn more, see [Transform JSON strings into JSON objects](/transforms/json-parsing) and [Remap JSON attribute fields to top-level log event fields](/transforms/remapper).

## A login issue for users with mixed-case email addresses is fixed

**September 17, 2025**

A bug that prevented some users with mixed-case email addresses from logging in to the Grepr UI is fixed.

## The invitations table in the UI now shows the roles of invited users

**September 17, 2025**

The **Invitations** table in the user management UI is updated to show the roles that were assigned when a user was invited to your organization.

## An issue affecting invitation acceptance is fixed

**September 10, 2025**

A bug preventing users from accepting an invitation to join their organization in Grepr is fixed.

## Improved search experience in Log Explorer

**September 10, 2025**

An issue with flickering search input in Log Explorer that occurs when you type new search queries is resolved. The search input now responds smoothly to user input, providing a better experience when exploring and filtering log data.

## Changes to improve the usability of help text in the Grepr UI

**September 10, 2025**

The Grepr UI is updated to improve the clarity and consistency of help text across pipelines, integrations, and data warehouse components. These changes make it easier for you to configure S3 data lakes, manage pipeline time ranges, and understand integration exceptions that occur.
