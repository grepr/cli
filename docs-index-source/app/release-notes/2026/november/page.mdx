# Release notes for November 2026

Grepr released these feature updates, improvements, and bug fixes in November 2026.

## November 23, 2026

### Other improvements and fixes

- {/* ENGT-7067 */} The default scan budget of an analytics query is 1 TiB, up from 100 GiB, for every kind of data.
- {/* ENGT-6905 */} Analyze and SQL queries that match values in a log's attributes run several times faster.
- {/* ENGT-6290 */} You can filter the **Users** page in organization settings by org role or team, including **No org role** and **No team**, with a count beside each option.
- {/* ENGT-7296 */} You can set how many runs an hour the churn specialist starts outside churn mode with its **Runs per hour outside churn mode** setting.
- {/* ENGT-7329 */} The decision step of an AI agent skips more routine log lines, such as successful requests and worker status messages, so fewer investigations start on them.
- {/* ENGT-7151 */} **System Logs** entries for pipeline syncs show how many sample events a sync carried instead of listing them, and very large entries are shortened.
- {/* ENGT-6905 */} Fixed an issue where Analyze and SQL queries that match values in a log's attributes failed on logs with deeply nested attributes.
- {/* ENGT-7185 */} Fixed an issue where code editors stayed blank or kept loading when your network blocked a third-party content delivery network.
- {/* ENGT-6290 */} Fixed several issues on the **Users** page, including users beyond the first 100 and pending invitations beyond the first 10 not showing, and later pages repeating the same members on self-hosted installs that sign in with Keycloak.
- {/* ENGT-7151 */} Fixed an issue where, in rare circumstances, a **System Logs** search failed.
- {/* ENGT-7330 */} Fixed an issue where an AI agent investigation failed when a sample event contained a very large integer.

## November 20, 2026

### Other improvements and fixes

- {/* ENGT-6853, ENGT-7017 */} The dataset menus in the navigation, Log Explorer, Trace Explorer, the **Agent Sessions** page, and the **SQL** page list only the datasets that hold the kind of data that page searches.
- {/* ENGT-7109 */} In pipelines you create from now on, a batch that a vendor rejects with a retryable error is retried until the vendor accepts it, instead of being dropped after three retries.
- {/* ENGT-7000 */} Datadog integrations have a **Forward sketches and service checks to Datadog** setting, off by default, that forwards the distributions and service checks your Datadog Agent sends to Grepr on to Datadog.
- {/* ENGT-6312 */} You can clone any log pipeline, including pipelines not created in the Grepr UI.
- {/* ENGT-7133 */} You can set an AI agent's **Hold during churn at** threshold, in signals per minute, to choose how high a pipeline's rate of new log patterns gets before the agent holds its investigations on that pipeline.
- {/* ENGT-7133 */} The churn specialist starts at most 10 runs an hour while none of your pipelines is in churn mode.
- {/* ENGT-7175, ENGT-7187 */} The churn specialist proposes one change for a whole family of similar log patterns instead of one variant at a time, and skips signals that an existing signal mask or drop rule already covers.
- {/* ENGT-7175 */} AI agent runs reuse cached prompts across runs, which lowers what each run costs with your model provider.
- {/* ENGT-6312 */} Fixed an issue where a SQL transform's metric output to Datadog could fail the pipeline when a metric value was missing.
- {/* ENGT-6312 */} Fixed an issue where, in rare circumstances, a pipeline that failed while starting showed as running.
- {/* ENGT-7206 */} Fixed an issue where, in rare circumstances, signing up failed with an error saying the organization name was taken.
- {/* ENGT-7205 */} Fixed an issue where, in rare circumstances, a person invited by email could not join your organization.

## November 18, 2026

### Other improvements and fixes

- {/* ENGT-7057 */} Log reducers mask whole words that contain both letters and digits by default, in new pipelines and in existing pipelines when they are upgraded. See [_](/transforms/reducer/configuration).
- {/* ENGT-7057 */} While a pipeline produces new log patterns at a high rate, AI agents hold back the investigations they would start on it and release them once the rate drops. See [_](/ai-agents/investigations).
- {/* ENGT-7057 */} The default queue limit of an AI agent is 200 queued investigations, down from 1,000. See [_](/ai-agents/create-an-agent).
- {/* ENGT-6970 */} The pipeline details page loads and refreshes faster for pipelines with a long version history.
- {/* ENGT-7045 */} Pipelines that scale up during a traffic spike reach their new capacity sooner.
- {/* ENGT-7003 */} Fixed several issues in Datadog log intake, including JSON log lines with escaped quotes that arrived without their service, host, and tags, and some log payloads that failed to process.
- {/* ENGT-7095 */} Fixed an issue where, in rare circumstances, log searches and Analyze queries failed for a while after the service was busy.
- {/* ENGT-7035 */} Fixed an issue where a trace pipeline could fail to restart after you changed the dataset it writes to.
- {/* ENGT-7057 */} Fixed an issue where, in rare circumstances, a pipeline that an AI agent watches could restart repeatedly on very long log messages.
- {/* ENGT-7057 */} Fixed an issue where an AI agent's signal masks did not match the end of very long log messages.
- {/* ENGT-6768 */} Fixed an issue where creating or updating an AI agent could fail with an error saying its service account was not found.
- {/* ENGT-6972 */} Fixed an issue where `grepr job:draft` failed on template-based pipelines that have reducer exceptions.
- {/* ENGT-6772 */} Fixed an issue where going back to a search in Log Explorer could run an analysis you did not ask for.
- {/* ENGT-7021 */} Security fixes.

## November 14, 2026

{/* ENGT-6740, ENGT-6745, ENGT-6850, ENGT-6852, ENGT-6901 */}
### Query logs and traces with SQL

You can now write one Grepr SQL query across up to four tables of a dataset's logs and traces on the new **SQL** page. Each table reads the dataset's logs or spans through its own filter under an alias, so one query can join logs to other logs or to the spans of their traces, aggregate the results of an aggregation, or rank groups against each other. Results show as a table, a line chart, or a top list, and you can share a query as a link. See [_](/queries/sql).

### Other improvements and fixes

- {/* ENGT-6744 */} Analyze's Grepr SQL functions include window functions, such as `ROW_NUMBER`, `RANK`, `LAG`, and `LEAD`, for ranking rows and comparing a row with the rows around it. See [_](/queries/analyze).
- {/* ENGT-6575, ENGT-6994 */} You can turn on **Filter signals with a decision model** for an AI agent, so a model from your OpenAI integration screens its queued log pattern signals and drops the ones an investigation would learn nothing from, at a confidence threshold you set.
- {/* ENGT-6575 */} The **Status** filter on an agent's investigations list lets you select several statuses at once, including **Skipped**.
- {/* ENGT-6808 */} Timestamps without a time zone on logs from Datadog, Splunk HEC, and New Relic sources, such as `2026-01-15 10:30:00.123`, are read as UTC, so these events keep their own time instead of the time Grepr received them.
- {/* ENGT-6357 */} Grok rules with syntax errors are rejected when you save a pipeline, as they are in Datadog. See [_](/transforms/grok/datadog-matchers).
- {/* ENGT-6969 */} In the Grepr CLI, `job:plan`, `job:draft`, and `job:apply` work only on template-based pipelines and point you to `job:update` for a pipeline defined as a job graph, and the `job:to-test` command and the `--sample-rate` and `--sample-burst` options of `job:draft` are removed. See [_](/cli).
- {/* ENGT-6746 */} Calendar presets in the time picker, such as **Today** and **Yesterday**, keep their names in the picker's label.
- {/* ENGT-6884 */} Fixed an issue where Analyze could return wrong values for array and map columns.
- {/* ENGT-6695 */} Fixed an issue where Analyze's results table showed no rows after you switched to it from a chart.
- {/* ENGT-6746, ENGT-6766 */} Fixed several issues in Analyze in Log Explorer, including queries refused because they were checked against the wrong dataset, the previous dataset's rows staying on screen after you switched datasets, a busy server's response shown as an error instead of a prompt to run again, and the page failing after fast edits in Safari.
- {/* ENGT-6357 */} Fixed several issues in grok parsing, including matcher arguments with a comma, such as a `date` pattern with `,SSS` milliseconds, that failed to parse, and rules that in rare circumstances failed with "Grok rule could not be found".
- {/* ENGT-6867 */} Fixed an issue where editing some integrations that a running pipeline uses, such as renaming them, was refused with an error saying the integration is in use.
- {/* ENGT-6887, ENGT-6971 */} Security fixes.

## November 9, 2026

{/* ENGT-6690 */}
### See the top values of each group with nested groups in Analyze

You can now break an Analyze query down as nested groups: the top values of one field and, under each of them, the top values of the next field, up to four levels deep. Each group shows its own subtotal, the results start with a grand total, and the header shows about how many values the first field has in total. See [_](/queries/analyze).

{/* ENGT-6756 */}
### Run agents on a schedule

You can now give an AI agent a schedule, with a cron expression, a time zone, and optional instructions for what each scheduled run should do. At each scheduled time, the agent starts an investigation without waiting for a signal, and its scheduled runs appear in the agent's investigations list. See [_](/ai-agents/subscriptions#schedule).

### Other improvements and fixes

- {/* ENGT-6690 */} When a search or Analyze query runs out of resources, the error now tells you to narrow the time range and try again.

## November 6, 2026

{/* ENGT-6651, ENGT-6741 */}
### Add location data to logs from IP addresses

You can now add a **GeoIP lookup** parsing step to a log pipeline. The step reads an IP address from an attribute you choose and adds the continent, country, state, city, coordinates, and time zone for that address to the event. Events without a known address pass through unchanged. See [_](/transforms/geoip).

{/* ENGT-6686 */}
### An optimized Grok parser

The new **Multi-grok parser** step parses logs with several sets of Grok rules in one step, and each set parses the logs that match its own filter.

### Other improvements and fixes

- {/* ENGT-6593 */} The `list_pipelines` tool of the Grepr MCP server leaves out deleted pipelines and batch jobs that ended more than six hours ago unless you set `all`, and returns pipeline definitions only through `get_pipeline`.
- {/* ENGT-5999 */} The `update_job` tool of the Grepr MCP server takes each sample log event as a JSON string, and the `test_grok` tool takes its rules, helper rules, and log sample as separate arguments, so agents on Gemini models can call both tools.
- {/* ENGT-6403 */} AI agents have an optional code mode that reduces how much of the agent's context its tools take up, and an agent's shell commands can run for up to 5 minutes.
- {/* ENGT-6572 */} AI agents have a new `reduce-pattern-churn` skill that fixes pattern churn, where one kind of log raises many new-pattern signals because an ID or number in it changes, by proposing signal masks and signal drop rules. See [_](/ai-agents/capabilities).
- {/* ENGT-6358 */} Fixed an issue where, in rare circumstances, a pipeline could stop scaling up to keep up with more traffic.
- {/* ENGT-6335 */} Fixed an issue where, in rare circumstances, a pipeline update that failed its last health check could not roll back to the previous version.
- {/* ENGT-6200 */} Fixed an issue where unsaved edits on a pipeline's page could be lost when the pipeline's status changed.
- {/* ENGT-6593 */} Fixed an issue where `grepr job:list` left out pipelines that were rolling back, verifying, or updating.
- {/* ENGT-6659 */} Fixed several issues in the issue board, including the page moving when a column reached its end and a card's tooltip stopping a column from scrolling.
- {/* ENGT-6653, ENGT-6655, ENGT-6656 */} Security fixes.
